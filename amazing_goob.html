Amazing Goob

What is Amazing Goob

Amazing Goob is a reverse platformer made for the GMTK Game Jam 2023, built around the theme "Role Reversal." Instead of controlling the character, you place and rotate platforms, each with its own mechanic, to guide an auto-running hero as far across the sky as possible.

Summarized Contribution

  • Worked on a 7-person team in 48 hours to build a game for the GMTK Game Jam 2023.
  • Designed the core gameplay loop and 3 unique platforms players place to guide the hero.
  • Scripted platform selection and placement, platform behaviors, object collection, and other core mechanics.
